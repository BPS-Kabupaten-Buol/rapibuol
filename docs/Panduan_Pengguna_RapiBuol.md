# 1. MASUK KE APLIKASI (LOGIN)

## Langkah 1: Membuka Aplikasi

```
🖥️  LANGKAH 1
```

> **CARI:** Buka browser (Chrome/Edge) di komputer Anda

> **[GAMBAR: Tampilan browser kosong, fokus pada address bar]**

---

```
🖥️  LANGKAH 2
```

> **KETIK:** Ketik alamat aplikasi di baris atas browser, lalu tekan Enter

> Contoh: `https://rapibuol.domain.com`

> **[GAMBAR: Address bar dengan alamat aplikasi]**

---

## Langkah 2: Mengisi Form Login

```
🖥️  LANGKAH 3
```

> **CARI:** Carilah kotak isian bertuliskan **"Email"**

> **[GAMBAR: Kotak isian Email yang diberi tanda panah]**

---

```
🖥️  LANGKAH 4
```

> **KETIK:** Ketik alamat email Anda menggunakan keyboard

> Contoh: `budi.susanto@bps.go.id`

> **TIPS:** Huruf besar/kecil TIDAK berpengaruh di email

> **[GAMBAR: Email sudah diketik di kotak isian]**

---

```
🖥️  LANGKAH 5
```

> **CARI:** Carilah kotak isian bertuliskan **"Password"**

> **[GAMBAR: Kotak isian Password yang diberi tanda panah]**

---

```
🖥️  LANGKAH 6
```

> **KETIK:** Ketik password Anda

> **[GAMBAR: Password disembunyikan dengan titik-titik]**

---

## Langkah 3: Masuk ke Aplikasi

```
🖥️  LANGKAH 7
```

> **CARI:** Carilah tombol **"Sign in"** (biasanya berwarna biru)

> **[GAMBAR: Tombol Sign in yang diberi tanda panah]**

---

```
🖥️  LANGKAH 8
```

> **KLIK:** Klik tombol **Sign in** sekali

> **[GAMBAR: Cursor klik pada tombol Sign in]**

---

```
✅ SELESAI LOGIN
```

> Jika berhasil, Anda akan masuk ke halaman **Dashboard**

> Jika gagal, akan muncul pesan error. Ulangi langkah dari awal.

> **[GAMBAR: Tampilan Dashboard setelah login berhasil]**

---

## JIKA GAGAL LOGIN

> **Pesan: "Email atau password salah"**

> 1. Pastikan email diketik dengan benar
> 2. Pastikan password diketik dengan benar
> 3. Perhatikan huruf besar/kecil di password (jika ada)
> 4. Hubungi admin IT jika lupa password

# 2. LUPA PASSWORD

> Gunakan langkah ini JIKA Anda lupa password dan tidak bisa masuk aplikasi.

---

```
🖥️  LANGKAH 1
```

> Di halaman login, carilah teks bertuliskan **"Forgot password?"**

> Teks ini biasanya ada di bawah kotak password

> **[GAMBAR: Posisi link Forgot password]**

---

```
🖥️  LANGKAH 2
```

> **KLIK:** Klik sekali pada teks **"Forgot password?"**

> **[GAMBAR: Cursor klik pada Forgot password]**

---

```
🖥️  LANGKAH 3
```

> Anda akan masuk ke halaman baru

> **KETIK:** Ketik alamat email Anda yang terdaftar

> **[GAMBAR: Kotak isian email untuk reset password]**

---

```
🖥️  LANGKAH 4
```

> **KLIK:** Klik tombol **"Continue"**

> **[GAMBAR: Tombol Continue]**

---

```
✅ SELESAI
```

> Sistem akan mengirim email untuk mereset password

> Buka email Anda, cari email dari sistem

> **TIPS:** Jika email tidak muncul, cek folder **SPAM/JUNK**

> **[GAMBAR: Contoh email reset password]**

---

```
🖥️  LANGKAH 5
```

> **BUKA EMAIL:** Klik link di dalam email tersebut

> **[GAMBAR: Link reset password di dalam email]**

---

```
🖥️  LANGKAH 6
```

> Ikuti instruksi di email untuk membuat password baru

> Password baru harus minimal **6 karakter**

> **[GAMBAR: Form password baru]**

# 6. MELIHAT DASHBOARD

## Apa itu Dashboard?

> Dashboard adalah halaman utama yang menampilkan:
> - Statistik aktivitas Anda
> - Aktivitas hari ini
> - Grafik aktivitas

---

```
🖥️  LANGKAH 1
```

> Setelah login, Anda akan langsung melihat **Dashboard**

> ATAU

> Klik menu **"Dashboard"** di sebelah kiri

> **[GAMBAR: Menu Dashboard]**

---

```
🖥️  LANGKAH 2 - MELIHAT TAB
```

> **CARI:** Terdapat tab-tab di bagian atas

> **[GAMBAR: Tab Dashboard Saya, Tim, Satker]**

---

```
🖥️  LANGKAH 3
```

> **KLIK TAB:**

> - **"Dashboard Saya"** - untuk melihat aktivitas pribadi Anda
> - **"Dashboard Tim"** - untuk kepala tim (jika ada)
> - **"Dashboard Satker"** - untuk pimpinan (jika ada)

> **[GAMBAR: Tab Dashboard Saya dipilih]**

---

```
🖥️  LANGKAH 4 - MEMBACA STATISTIK
```

> **CARI:** Kartu-kartu statistik di bagian atas

> **[GAMBAR: Kartu statistik]**

---

> **MEMAHAMI KARTU STATISTIK:**

| Kartu | Arti |
|-------|------|
| **Total Kegiatan** | Berapa kali Anda input hari ini |
| **Selesai Bulan Ini** | Berapa aktivitas selesai bulan ini |
| **Rata-rata Tugas** | Rata-rata tugas per minggu |

---

```
🖥️  LANGKAH 5 - MELIHAT AKTIVITAS HARI INI
```

> **CARI:** Tabel di bagian bawah bertuliskan **"Daftar Tugas Hari Ini"**

> **[GAMBAR: Tabel tugas hari ini]**

> Di sini terlihat aktivitas yang sudah dan belum selesai

---

```
🖥️  LANGKAH 6 - MENAMBAH AKTIVITAS DARI DASHBOARD
```

> **KLIK:** Tombol **"Aktivitas Baru"** di pojok kanan bawah

> **[GAMBAR: Tombol Aktivitas Baru di Dashboard]**

# TIPS PENTING

## ✅ YANG BOLEH DILAKUKAN

- **Lambat memahami?** Tidak apa-apa, baca berulang kali
- **Lupa langkah?** Simpan panduan ini di komputer Anda
- **Tidak yakin?** Tanyakan ke rekan kerja atau admin IT
- **Salah input?** Bisa diedit atau dihapus dan dibuat ulang

## ❌ YANG TIDAK BOLEH

- Jangan bagikan password ke orang lain
- Jangan klik tombol acak tanpa membaca
- Jangan panik jika ada pesan error
- Jangan ragu untuk bertanya
