## BAB 1: PANDUAN LOGIN

### 1.1 Halaman Login

Halaman login adalah gerbang utama untuk mengakses sistem. Pengguna harus memasukkan kredensial yang valid untuk dapat masuk ke dalam sistem.

### 1.2 Langkah-langkah Login

Ikuti langkah-langkah berikut untuk login ke sistem:

| Langkah | Deskripsi |
|---------|----------|
| **Langkah 1** | Buka halaman login sistem. Anda akan melihat form login dengan dua field: Email dan Password. |
| **Langkah 2** | Masukkan alamat email Anda yang sudah terdaftar dalam sistem di field "Email". Contoh: nama@email.com |
| **Langkah 3** | Masukkan password Anda di field "Password". Password harus minimal 6 karakter. |
| **Langkah 4** | Klik tombol "Sign in" untuk melanjutkan. Jika kredensial valid, Anda akan diarahkan ke halaman Dashboard. |

> **Catatan:** Jika email atau password salah, sistem akan menampilkan pesan error.

### 1.3 Fitur Tambahan di Halaman Login

Pada halaman login terdapat beberapa fitur tambahan yang dapat digunakan:

- **Lupa Password:** Link untuk mereset password jika lupa. Klik pada teks "Forgot password?" di bawah field password.
- **Show/Hide Password:** Tombol untuk menampilkan atau menyembunyikan password yang diketik.

### 1.4 Troubleshooting Login

> **Tips Penting**
> - Pastikan email dan password benar
> - Periksa koneksi internet Anda
> - Clear cache browser jika mengalami masalah
> - Hubungi administrator jika lupa password

## BAB 2: PANDUAN LUPA PASSWORD

### 2.1 Kapan Menggunakan Fitur Lupa Password

Fitur "Lupa Password" digunakan ketika Anda tidak dapat mengingat password akun Anda. Sistem akan mengirimkan link reset password ke email terdaftar.

### 2.2 Langkah-langkah Reset Password

| Langkah | Deskripsi |
|---------|----------|
| **Langkah 1** | Di halaman login, klik pada link "Forgot password?" yang terletak di bawah field password. |
| **Langkah 2** | Anda akan diarahkan ke halaman reset password. Masukkan alamat email yang terdaftar. |
| **Langkah 3** | Klik tombol "Continue" untuk mengirim request reset password. |
| **Langkah 4** | Sistem akan mengirimkan email reset password ke alamat email yang dimasukkan. Buka email dan klik link reset password. |
| **Langkah 5** | Ikuti instruksi di email untuk membuat password baru. |

> **Catatan:** Link reset password memiliki masa berlaku terbatas. Segera gunakan setelah menerima email.

### 2.3 Hal yang Perlu Diperhatikan

- Pastikan email yang dimasukkan adalah email yang terdaftar di sistem.
- Periksa folder Spam/Junk jika email tidak muncul di inbox.
- Password baru harus memenuhi kriteria minimum (minimal 6 karakter).
- Setelah reset berhasil, Anda dapat login dengan password baru.

## BAB 3: PANDUAN MENGELOLA AKTIVITAS

### 3.1 Akses Menu Aktivitas

Menu Aktivitas dapat diakses melalui:
- **Sidebar menu** di sebelah kiri layar
- **Tab navigasi** di Dashboard

### 3.2 Menambah Aktivitas Baru

Anda dapat menambahkan aktivitas baru melalui dua cara:

1. **Tombol "Aktivitas Baru"** di halaman Dashboard (floating button di pojok kanan bawah)
2. **Tombol "+"** di halaman daftar Aktivitas
   - Mobile: icon round
   - Desktop: tombol dengan teks

#### Form Tambah Aktivitas

Isi field-field berikut dalam form aktivitas:

| Field | Deskripsi |
|-------|----------|
| **Deskripsi** | Jelaskan aktivitas yang dilakukan. Field ini **wajib diisi**. |
| **Tanggal** | Pilih tanggal pelaksanaan aktivitas. Default adalah tanggal hari ini. |
| **Waktu Mulai** | Waktu mulai aktivitas (opsional). Format: JJ:MM |
| **Waktu Selesai** | Waktu selesai aktivitas (opsional). Format: JJ:MM |
| **Volume** | Jumlah/kuantitas output aktivitas. Minimal 0. |
| **Satuan** | Satuan pengukuran volume (contoh: dokumen, orang, kali). |
| **Tim Pemberi Tugas** | Tim yang memberikan tugas atau yang terkait dengan aktivitas. |
| **Link Bukti Dukung** | Link dokumen pendukung atau bukti pelaksanaan (opsional). |
| **Tandai Selesai** | Centang jika aktivitas sudah selesai dikerjakan. |

Setelah mengisi form, klik **"Simpan"** untuk menyimpan aktivitas baru.

### 3.3 Mengedit Aktivitas

Untuk mengedit aktivitas yang sudah ada, ikuti langkah-langkah berikut:

| Langkah | Deskripsi |
|---------|----------|
| **Langkah 1** | Buka halaman daftar Aktivitas atau lihat aktivitas di Dashboard. |
| **Langkah 2** | Klik ikon menu (tiga titik) pada baris aktivitas yang ingin diedit. |
| **Langkah 3** | Pilih opsi **"Ubah"** dari menu dropdown. |
| **Langkah 4** | Form edit akan muncul. Ubah field-field yang diperlukan. |
| **Langkah 5** | Klik tombol **"Simpan"** untuk menyimpan perubahan atau **"Tutup"** untuk membatalkan. |

### 3.4 Menghapus Aktivitas

> **Peringatan:** Penghapusan aktivitas bersifat permanen. Data yang sudah dihapus tidak dapat dikembalikan. Pastikan Anda benar-benar ingin menghapus aktivitas sebelum mengkonfirmasi.

| Langkah | Deskripsi |
|---------|----------|
| **Langkah 1** | Buka halaman daftar Aktivitas. |
| **Langkah 2** | Klik ikon menu (tiga titik) pada baris aktivitas yang ingin dihapus. |
| **Langkah 3** | Pilih opsi **"Hapus"** dari menu dropdown. |
| **Langkah 4** | Konfirmasi penghapusan pada dialog konfirmasi yang muncul. |
| **Langkah 5** | Klik **"Hapus"** untuk melanjutkan atau **"Batal"** untuk membatalkan. |

## BAB 4: PANDUAN DASHBOARD

### 4.1 Pengertian Dashboard

Dashboard adalah halaman utama setelah login yang menampilkan ringkasan aktivitas dan statistik kerja. Dashboard memiliki tampilan berbeda berdasarkan peran/jabatan pengguna.

### 4.2 Tab Dashboard

Terdapat tiga jenis tab Dashboard:

| Tab | Akses | Deskripsi |
|-----|-------|----------|
| **Dashboard Saya** | Semua pengguna | Menampilkan statistik dan aktivitas personal |
| **Dashboard Tim** | Team Leader | Menampilkan performa anggota tim |
| **Dashboard Satker** | Kepala Satker | Menampilkan pengawasan makro organisasi |

### 4.3 Dashboard Saya (User)

#### Informasi Profil

Bagian atas Dashboard menampilkan informasi profil pengguna meliputi:
- Nama lengkap pengguna
- Email terdaftar
- Status akun (Aktif)

#### Kartu Statistik

| Kartu | Deskripsi |
|-------|----------|
| **Total Kegiatan** | Jumlah total aktivitas yang diinput untuk hari ini |
| **Selesai Bulan Ini** | Jumlah aktivitas yang ditandai selesai dalam bulan berjalan |
| **Rata-rata Tugas** | Rata-rata jumlah tugas per minggu dalam bulan ini |

#### Heatmap Aktivitas

Grafik heatmap menampilkan aktivitas 3 bulan terakhir dengan warna yang menunjukkan intensitas aktivitas per hari.

#### Daftar Tugas Hari Ini

Tabel yang menampilkan semua aktivitas yang dijadwalkan untuk hari ini, termasuk:

- Deskripsi aktivitas
- Waktu mulai dan selesai
- Volume dan satuan
- Status (Selesai/Pending)

### 4.4 Dashboard Tim (Team Leader)

Dashboard Tim dirancang untuk pemimpin tim dengan fitur berikut:

#### Kartu Statistik Tim

| Kartu | Deskripsi |
|-------|----------|
| **Realisasi Tim** | Perbandingan aktivitas selesai dengan total aktivitas |
| **Anggota Aktif Hari Ini** | Jumlah anggota yang sudah input aktivitas |
| **Belum Lapor** | Jumlah anggota yang belum input hari ini |

#### Filter Periode

Team Leader dapat memfilter data berdasarkan periode:

- **Hari Ini:** Menampilkan aktivitas hari ini
- **Minggu Ini:** Menampilkan aktivitas dalam minggu berjalan
- **Bulan Ini:** Menampilkan aktivitas dalam bulan berjalan

#### Tabel Performa Anggota

Menampilkan daftar anggota tim dengan statistik kinerja masing-masing.

#### Tabel Belum Lapor

Daftar anggota yang belum menginput aktivitas minimal 1 kali hari ini. Berguna untuk monitoring disiplin tim.

#### Detail Aktivitas Anggota

Team Leader dapat melihat detail aktivitas setiap anggota tim dengan mengklik tombol **"Detail"**.

### 4.5 Dashboard Satker (Kepala Satker)

Dashboard Satker dirancang untuk pengawasan makro dengan fitur lengkap:

#### Kartu Statistik Satker

| Kartu | Border | Deskripsi |
|-------|--------|----------|
| **Total Output** | Biru | Jumlah aktivitas selesai bulan ini |
| **Kepatuhan Harian** | Hijau | Persentase pegawai yang melapor hari ini |
| **Total Pegawai** | Ungu | Jumlah total pegawai terdaftar |
| **Belum Melapor** | Merah/Orange | Jumlah pegawai yang belum input |

#### Grafik Analytics

- **Trend Aktivitas Harian:** Grafik garis fluktuasi produktivitas harian
- **Beban/Output per Tim:** Grafik batang perbandingan aktivitas antar tim

#### Master Data Pantauan Pegawai

Tabel lengkap yang menampilkan seluruh pegawai dengan informasi:

- Nama Pegawai
- Tim
- Jumlah Aktivitas Bulan Ini
- Status Lapor Hari Ini (Sudah/Belum)
- Tombol Detail untuk melihat aktivitas individual

## LAMPIRAN

### A. Keyboard Shortcuts

| Shortcut | Fungsi |
|----------|--------|
| `Ctrl + /` | Membuka menu pencarian cepat |
| `Esc` | Menutup dialog/modal yang terbuka |

### B. Role-based Access Control

Sistem memiliki tiga level akses:

| Role | Akses |
|------|-------|
| **User** | Pengguna biasa - akses ke Dashboard Saya dan halaman Aktivitas |
| **Team Leader** | Pemimpin tim - akses Dashboard Saya + Dashboard Tim |
| **Kepala Satker** | Atasan BPS - akses ke semua dashboard termasuk Dashboard Satker |

### C. Kontak Dukungan

> **Butuh Bantuan?**
> Jika mengalami kesulitan atau menemukan bug dalam sistem, silakan hubungi administrator sistem melalui email resmi atau melalui menu **Help Center** di sidebar.
